# 一元一次方程式：去括號與移項（練習課範例）

> 課型：練習課｜這是技能附帶的**示範教案**，沒有真實課堂資料。文中所有學生表現都是「預期情況」，不是觀察結果。

## A. 課堂基本資料

- 年級：七年級
- 課題：一元一次方程式：去括號與移項
- 課時：40分鐘
- 核心學習目標：能正確去括號（含括號前的負號）與移項，解出一元一次方程式，並代回原式檢驗
- 先備知識：等量公理、移項法則、分配律、整數四則運算
- 教學重點：去括號時括號內每一項都要乘；移項要變號；代回原式檢驗
- 學習難點：括號前是負號時，括號內每一項都要變號

換層規則：第一輪做對且有檢驗 → 第二輪往上一層；用到兩個以上提示 → 第二輪留在同層；第二輪 A 層也要完成「驗證一個解」，不只做計算。

### 第 1 階段　0–5 分鐘　診斷起步題

- 教師活動：展示目標；出診斷題「解 \(3x-5=10\)，移項後是？」；點選項計票。
- 學生活動：手勢作答；依結果決定第一輪的起始層。
- 教學資源：簡報 1-1、1-2。
- 理解檢查：選項 B（移項沒變號）、C（漏除）各對應一種程序錯誤。
- 可能困難（預期情況）：少數學生不確定「移項」是哪一步。
- 應對策略：直接進入 2-1 回顧，不在此處講解。

### 第 2 階段　5–10 分鐘　方法回顧與關鍵步驟

- 教師活動：拖步驟滑桿，每步請學生說理由；2-2 問「怎樣確認答案對不對？」。
- 學生活動：口頭說理由；手勢作答。
- 教學資源：簡報 2-1（步驟滑桿）、2-2。
- 理解檢查：2-2 選項分布。
- 可能困難（預期情況）：認為「答案是整數就對」。
- 應對策略：用 4-2 A 層答案 \(\frac{5}{2}\) 說明解可以是分數。

### 第 3 階段　10–25 分鐘　分層練習兩輪＋巡視

- 教師活動：兩關各計時 5 分鐘；巡視時依提示階梯支援（重讀題目 → 提示變號 → 寫出去括號結果 → 示範一步）；記錄代表性錯誤供第 4 階段使用。
- 學生活動：第一輪基本題型；第二輪條件變化（驗證解、情境列式、求參數）。
- 教學資源：簡報 3-1（第一關）、3-2（第二關）；每頁都有三層題目、各層提示與 5 分鐘倒數。
- 理解檢查：巡視紀錄「漏乘第二項」「移項沒變號」「括號前負號」的人數。
- 可能困難（預期情況）：B 層情境題不知道設什麼為 x。
- 應對策略：提示「題目問什麼，就設什麼為 x」。

### 第 4 階段　25–35 分鐘　錯誤門診＋再試一題

- 教師活動：展示去識別化錯誤（若巡視時有收集到，優先用真實錯誤）；先請學生代回 \(x=\frac{7}{3}\) 看左右是否相等，再找錯誤步驟。
- 學生活動：代回、找錯、說明原因；再試一題。
- 教學資源：簡報 4-1、4-2。
- 理解檢查：再試一題的正確率。
- 可能困難（預期情況）：知道錯，但說不出原因。
- 應對策略：用「\(-(x+3)=-1\times(x+3)\)」連到分配律。

### 第 5 階段　35–40 分鐘　出口題＋自我評估

- 教師活動：發出口題；收回分三類；請學生舉手自評。
- 學生活動：獨立完成並寫代回檢驗；自評。
- 教學資源：簡報 5-1、5-2。
- 理解檢查：出口題＋自評人數。

## C. 課堂練習

| 層次 | 題目 | 答案 | 解題說明／提示 |
|------|------|------|----------------|
| 第一輪 A | 解 \(x+7=12\) | \(x=5\) | \(+7\) 移項變 \(-7\) |
| 第一輪 B | 解 \(3(x-2)=x+8\) | \(x=7\) | \(3x-6=x+8\)，\(2x=14\) |
| 第一輪 C | 解 \(5-2(x-1)=3x-8\) 並檢驗 | \(x=3\) | \(7-2x=3x-8\)，\(5x=15\)；代回兩邊都是 1 |
| 第二輪 A | \(x=2\) 是 \(4x-3=5\) 的解嗎？ | 是 | \(8-3=5\) |
| 第二輪 B | 3 支筆加一本 25 元筆記本共 70 元，筆一支幾元？ | 15 元 | \(3x+25=70\) |
| 第二輪 C | 若 \(x=2\) 是 \(ax+3=11\) 的解，求 a | \(a=4\) | \(2a+3=11\) |
| 再試 A | 解 \(6-(x+1)=x\) | \(x=\frac{5}{2}\) | \(5-x=x\) |
| 再試 B | 解 \(2x-(3x-4)=1\) | \(x=3\) | \(-x+4=1\) |
| 再試 C | 某同學解 \(7-(2x-5)=x\) 得 \(\frac{2}{3}\)，錯在哪？ | \(-5\) 應變 \(+5\)；\(x=4\) | \(12-2x=x\)，\(3x=12\) |

## D. 典型錯誤分析

- 錯誤示例（預期錯誤）：\(4-(x+3)=2x\) 寫成 \(4-x+3=2x\)，得 \(x=\frac{7}{3}\)。
- 可能原因：程序錯誤，括號前是負號時只把第一項變號。
- 診斷問題：「把 \(\frac{7}{3}\) 代回原式，左右相等嗎？\(-(x+3)\) 等於 \(-1\) 乘以什麼？」
- 教師引導方式：代回發現不成立 → 找第一個不等價的步驟 → 用分配律說明。
- 修正後練習：再試一題（4-2）。
- 其他預期錯誤：移項沒變號（程序）；去括號漏乘第二項（程序）；\(3\times(-2)\) 算成 6（粗心）。

## E. 出口題及評估

- 出口題：解 \(3-2(x-4)=5\)，並代回檢驗。
- 參考答案：\(3-2x+8=5\)，\(11-2x=5\)，\(x=3\)；代回 \(3-2(3-4)=3+2=5\)。
- 達標判準：

| 結果 | 判準 | 下一節課安排 |
|------|------|--------------|
| 已掌握 | 去括號、移項正確，且寫出代回檢驗 | 進入應用題列式 |
| 部分掌握 | 答案正確但沒有檢驗，或有一處計算小錯 | 起步題強調代回檢驗 |
| 尚未掌握 | 把 \(-2(x-4)\) 展開成 \(-2x-8\) | 下一節小組從分配律與負號重練 |
