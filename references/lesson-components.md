# 課堂元件 LS（lesson.js）使用說明

`lesson.js` 提供 10 個課堂元件，在投影片的 `visual: (h) => …` 內呼叫。每個元件對應 AGENTS 三項原則中的一個環節：

| 元件 | 用在 | 對應原則 |
|------|------|----------|
| `LS.goals` | 學習目標、本節總結、概念脈絡 | 每位學生知道本節要做到什麼 |
| `LS.hook` | 新課的懸念引入（情境圖或短片＋先猜＋懸念） | 引起注意、設置懸念、引出新課 |
| `LS.tasks` | 熱身題、闖關練習（可加倒數）、升級挑戰 | 原則一：每位學生都有明確任務（A／B／C 三層同頁＋提示階梯） |
| `LS.tiers` | 純題目的三層一覽（選用） | 原則一：學生看完三層再自己選層，分層不是固定標籤 |
| `LS.anim` | 動畫引入（分幕動畫＋字幕＋預錄語音，例：粵語旁白） | 引起動機、建立直觀；看完要學生說出發現 |
| `LS.check` | 講解中的理解檢查、診斷題、前測 | 原則二：教師能及時發現困難（全班同步作答＋計票＋迷思說明） |
| `LS.mistake` | 典型錯誤分析 | 原則二：分辨概念／程序／粗心錯誤；不公開學生身份 |
| `LS.timer` | 單獨的倒數頁（少用；分層練習請用 `LS.tasks` 的 `timer`） | 原則一：給學生安靜思考時間 |
| `LS.exit` | 出口題 | 原則三：留下學習證據（判準與後續安排只寫在教案） |
| `LS.tally` | 自我評估、舉手統計 | 原則三：學生反思自己的理解 |

共通規則：

- **投影畫面是給學生看的**：階段名稱、小節名稱、左欄 `points`、計時頁的 `tips` 都寫成學生的任務或自我提醒（例：「抓錯偵探」「專注時間」「先找斜邊了嗎？」），不寫教師的動作（巡視、計票、判斷誰該補救）。教師用的說法寫在教案。

- 內容字串可含 HTML 與行內數學 `\\( \\)`（JS 字串內雙反斜線）。
- 元件只寫入 `h`，不要再對 `h.innerHTML` 另外賦值。
- 換頁再回來時，票數、提示、答案、步驟與倒數都會還原（以 `sec` 區分頁面，所以每頁 `sec` 不可重複）。教具列的長條圖按鈕可看票數與下載 CSV。
- 教學文字一律 28pt。右欄約 20 個中文字一行，**題目 1～2 行、每條提示 1 行**為原則。
- 按鈕逐步揭露（提示、答案、迷思、判準），初次畫面只顯示題目，所以 `?check` 量的是「初次畫面」。揭露後若超出欄高，欄位可以捲動，但仍建議縮短文字。
- 驗證工具只確認元件初次繪製沒有錯誤；**按鈕揭露後的內容（提示、答案、迷思說明）要人工點一遍確認**。

---

## LS.goals(h, {head, items, note})

```js
visual: (h) => LS.goals(h, {
  head: '本節學習目標',
  items: ['能說出直角三角形三邊的關係', '能求出直角三角形的未知邊'],
  note: '選填：一行補充'
})
```

## LS.tasks(h, tiers, {timer})

```js
// 一般分層題
visual: (h) => LS.tasks(h, [
  { tier: 'A', q: '直角邊 3、4，斜邊是多少？', hints: ['斜邊在直角的對面。', '先算 \\(3^2+4^2\\)。'], ans: '5' },
  { tier: 'B', q: '斜邊 13、一直角邊 5，另一直角邊？', hints: ['斜邊的平方最大。'], ans: '12' },
  { tier: 'C', q: '為什麼 \\(1,1,2\\) 不能是直角三角形三邊？', ans: '\\(1^2+1^2\\neq2^2\\)' }
])
// 專注時間：同一頁頂端加倒數（分鐘）
visual: (h) => LS.tasks(h, [ /* 同上 */ ], { timer: 7, watch: ['找錯斜邊（概念）', '忘了開方（程序）'] })
```

- **A 基礎支持、B 核心達標、C 延伸挑戰三層同一頁同時顯示**，每層有自己的「提示」「答案」按鈕，互不影響；學生自選一層，做完往上挑戰。
- `tier`：`'A'`、`'B'`、`'C'`；`name` 可自訂層名。
- `hints`：提示階梯，按一次多顯示一條。依 AGENTS 支持次序排列：重讀題目 → 相關概念 → 部分線索 → 關鍵步驟。
- `watch`：巡視觀察重點，不投影，只印在教師版的巡視觀察表。
- `timer`：分鐘數。**專注時間一定要和題目同頁**，不做只有時間的頁面。可再用 `label` 改計時列名稱（預設「專注時間」）。
- 三層圍繞**同一個核心概念**；C 層要求解釋、比較、推理或遷移，不是同型題加量。
- 題目每題 1 行為原則（約 20 字），最多一層 2 行；720p 用 `--window 1310x862` 檢查。提示與答案全部打開時欄位可以捲動。

## LS.check(h, {q, options, tally})

```js
visual: (h) => LS.check(h, {
  q: '直角三角形三邊 6、8、10，哪一邊是斜邊？',
  options: [
    { t: '10', ok: true, why: '斜邊最長，在直角對面。' },
    { t: '8', why: '把「最後寫的數」當斜邊。' },
    { t: '6', why: '把「直立的邊」當斜邊。' }
  ]
})
```

- 每個錯誤選項都要對應一種**典型錯誤或迷思**，`why` 寫出成因。不要寫成單純「錯」。
- 學生用手勢或小白板同步作答；老師點右側數字計票，再按「揭曉」。
- 設 `tally: false` 可以不顯示計票。
- 判讀方式寫在左欄 `points` 或教案：例如「超過三成選 B，回到 2-2 重講」。

## LS.mistake(h, {who, q, steps, wrong, why, fix})

```js
visual: (h) => LS.mistake(h, {
  q: '直角三角形兩直角邊 5、12，求斜邊。',
  steps: ['\\(c=5+12\\)', '\\(c=17\\)'],
  wrong: 0,
  why: '概念錯誤：把「平方和」當成「邊長和」。',
  fix: '\\(c^2=5^2+12^2=169\\)，\\(c=13\\)'
})
```

- `who` 預設「某位同學的解法（不公開姓名）」。**不得**放真實學生姓名或可辨識的資訊。
- `wrong`：錯誤步驟的序號（從 0 起算）。
- `why` 要標明錯誤類型：概念錯誤、程序錯誤或粗心失誤。
- 錯誤示例可以來自教師提供的真實作答（去識別化），或標註「預期錯誤」。

## LS.timer(h, {min, label, tips})

```js
visual: (h) => LS.timer(h, { min: 7, label: '專注時間', tips: ['先找斜邊：直角對面那條', '已知斜邊？改用減法'] })
```

- 按「開始」才倒數。換頁後繼續倒數，時間到會響鈴（🔔 可關）。
- `tips` 是給學生看的自我檢查提醒，1～2 條。教師的巡視觀察重點寫在教案，不放在投影畫面。

## LS.exit(h, {q, ans, rubric})

```js
visual: (h) => LS.exit(h, {
  q: '梯子長 10 m，底端離牆 6 m，頂端多高？',
  ans: '8 m',
  rubric: {
    mastered: '列式正確得 8 m → 下一節進入應用題',
    partial: '列式對、計算或開方錯 → 起步題練開方',
    notyet: '把邊長相加或找錯斜邊 → 小組回到面積圖'
  }
})
```

- 出口題 2～3 分鐘可完成、答案容易快速檢查，不是示範題的機械重複；**換情境、換數字**。
- `rubric` **不會投影**，只印在 `handout.html` 的教師版，讓老師批改小紙條時分三類。

## LS.tally(h, {q, levels})

```js
visual: (h) => LS.tally(h, { q: '我能用畢氏定理求未知邊', levels: ['已掌握', '部分掌握', '尚未掌握'] })
```

- 老師點數字計票，長條圖即時更新。只記人數，不記姓名。

## LS.hook(h, {story, pic, video, guess, ask, later})

```js
visual: (h) => LS.hook(h, {
  pic: svg('0 0 440 250', /* 情境圖 */ ''),        // 或 video: 'media/hook.mp4'
  story: '屏幕寬 40 cm、高 30 cm，盒子上卻寫「對角線 50 cm」。',
  guess: ['寫錯了，應該是 70 cm', '沒寫錯，就是 50 cm', '還不確定'],
  ask: '40＋30＝70，為什麼盒子寫 50？',
  later: '學完今天的內容，你就能證明誰對！'
})
```

- 用在新課第一、二階段之間（約 3 分鐘）。畫面分三步：👀 看情境 → 🤔 猜一猜（可舉手計票）→ ❓ 懸念登場。
- 懸念要和本節核心概念直接相關，**學完才答得出來**；當下**不給答案**，並在課末頁（`6-2`）回來揭曉。
- 猜測選項放學生的真實直覺（常常是錯的），加一個「還不確定」，讓每個人都能參與。
- 短片：`video` 指向 `site\media\` 內的本機 mp4，並確認有權使用；不要連外部網址，上課才不受網路影響。換頁會自動暫停。

## LS.tiers(h, tiers)

只列題目、沒有提示與答案的三層一覽（`fit` 可寫「適合誰」）。一般分層題直接用 `LS.tasks` 即可，三層已經同頁；只有在需要「純題目總覽」時才用它。

## LS.anim(h, {scenes, vb, lang})

```js
visual: (h) => LS.anim(h, {
  vb: '0 0 440 250',
  scenes: [
    { say: '呢個係直角三角形。', audio: 'audio/s1.mp3', dur: 6, d: k => SV.poly(...) },
    { say: '喺兩條直角邊上面砌正方形。', audio: 'audio/s2.mp3', dur: 6, d: k => /* k 從 0 到 1 長出正方形 */ '' }
  ]
})
```

- 每一幕：`say`（字幕，投影 28pt，**1～2 行**）、`d(k)`（該幕的 SVG 片段，`k` 為 0～1 的進度；前面各幕自動以 `d(1)` 疊加）、`dur`（秒，最短播放時間）、`audio`（選填，預錄語音）。
- 第一幕的 `d(0)` 必須畫出東西（驗證工具會檢查圖形元素不可變成 0）。
- 動畫用來建立直觀、留下問題，**不要先講出結論或公式**。
- 播放：按 ▶ 才開始。每一幕播完 `dur` 秒**而且**語音講完才換下一幕；可暫停、可拖進度條、可關聲音；換頁自動停止。
- 沒有 `audio` 時，若電腦有 `lang`（預設 `zh-HK`）語音就由瀏覽器朗讀字幕；沒有就只顯示字幕。
- 進度條是 `<input type="range">`，驗證工具會掃過全部 0.01 步進值，檢查每一個畫面。
- SVG 中文字 `font-size` 至少 30（viewBox 寬 440 時），720p 投影才不會小於 28pt。

### 產生粵語語音（預錄 mp3）

1. 寫 `narration.json`（`text` 是「讀出來的字」：數字寫中文、a² 寫「a 嘅平方」）：
   ```json
   { "voice": "zh-HK-HiuGaaiNeural", "rate": "-5%",
     "items": [ {"file": "s1.mp3", "text": "呢個係直角三角形。兩條短邊叫做直角邊，最長嗰條叫做斜邊。"} ] }
   ```
2. 用**已安裝 edge-tts** 的 Python 執行（本技能不會安裝套件）：
   ```powershell
   <有 edge-tts 的 python> "$S\scripts\make_audio.py" --config "output\<名稱>\narration.json" --out "output\<名稱>\site\audio"
   ```
3. 在 `chN.js` 的每一幕寫 `audio: 'audio/s1.mp3'`。

注意：edge-tts 會把 `text` 送到微軟 Edge 朗讀服務（需要網路，非正式公開介面）。旁白只放教學內容，不放學生姓名或個資。產生後 mp3 留在 `site\audio\`，上課播放不需要網路。沒有 edge-tts 或使用者不同意送出文字時，省略 `audio`，改用字幕（＋瀏覽器語音）。

## 列印紙本（handout.html）

`site\handout.html` 直接讀同一份 `chN.js`，不用另外寫題目：

| 紙本 | 內容 | 來源 |
|------|------|------|
| 學生學習單 | 各 `LS.tasks` 頁的三層題目與作答空間；A 層附第一條提示；**沒有答案** | `q`、`hints[0]` |
| 出口小紙條 | 一張 A4 六份，裁開派發 | `LS.exit` 的 `q` |
| 教師版 | 巡視觀察表、出口題判準、全部提示與答案；**不要投影或派發** | `watch`、`rubric`、`hints`、`ans` |

題目裏的情境圖不會印出來；需要圖的題目，題目文字要能單獨看懂。`validate_deck.py` 會檢查紙本的公式與學生版沒有答案，但列印效果要在瀏覽器的列印預覽確認。
