# 課堂元件 LS（lesson.js）使用說明

`lesson.js` 提供 7 個課堂元件，在投影片的 `visual: (h) => …` 內呼叫。每個元件對應 AGENTS 三項原則中的一個環節：

| 元件 | 用在 | 對應原則 |
|------|------|----------|
| `LS.goals` | 學習目標、本節總結、概念脈絡 | 每位學生知道本節要做到什麼 |
| `LS.tasks` | 起步題、分層練習、分層鞏固 | 原則一：每位學生都有明確任務（A／B／C＋提示階梯） |
| `LS.check` | 講解中的理解檢查、診斷題、前測 | 原則二：教師能及時發現困難（全班同步作答＋計票＋迷思說明） |
| `LS.mistake` | 典型錯誤分析 | 原則二：分辨概念／程序／粗心錯誤；不公開學生身份 |
| `LS.timer` | 獨立嘗試＋巡視 | 原則一：給學生安靜思考時間 |
| `LS.exit` | 出口題 | 原則三：留下學習證據＋三類學生後續安排 |
| `LS.tally` | 自我評估、舉手統計 | 原則三：學生反思自己的理解 |

共通規則：

- 內容字串可含 HTML 與行內數學 `\\( \\)`（JS 字串內雙反斜線）。
- 元件只寫入 `h`，不要再對 `h.innerHTML` 另外賦值。
- 教學文字一律 28pt。右欄約 20 個中文字一行，**題目 1～2 行、每條提示 1 行**為原則。
- 按鈕逐步揭露（提示、答案、迷思、判準），初次畫面只顯示題目，所以 `?check` 量的是「初次畫面」。揭露後若超出欄高，欄位可以捲動，但仍建議縮短文字。
- 驗證工具只確認元件初次繪製沒有錯誤；**按鈕揭露後的內容（提示、答案、迷思說明）要人工點一遍確認**。

---

## LS.goals(h, {head, items, note})

```js
visual: (h) => LS.goals(h, {
  head: '本節學習目標',
  items: ['能說出直角三角形三邊的關係', '能求出直角三角形的未知邊'],
  note: '選填：一行補充'
})
```

## LS.tasks(h, tiers, {start})

```js
visual: (h) => LS.tasks(h, [
  { tier: 'A', q: '直角邊 3、4，斜邊是多少？', hints: ['斜邊在直角的對面。', '先算 \\(3^2+4^2\\)。'], ans: '5' },
  { tier: 'B', q: '斜邊 13、一股 5，另一股？', hints: ['斜邊的平方最大。'], ans: '12' },
  { tier: 'C', q: '為什麼 \\(1,1,2\\) 不能是直角三角形三邊？', ans: '\\(1^2+1^2\\neq2^2\\)，而且 1＋1 不大於 2' }
], { start: 'B' })
```

- `tier`：`'A'`（基礎支持）、`'B'`（核心達標）、`'C'`（延伸挑戰）；`name` 可自訂層名。
- `hints`：提示階梯，按一次「給提示」多顯示一條。依 AGENTS 支持次序排列：重讀題目 → 相關概念 → 部分線索 → 關鍵步驟。
- 三層圍繞**同一個核心概念**；C 層要求解釋、比較、推理或遷移，不是同型題加量。
- 只給一層時不顯示分頁，改顯示層標籤（適合「再試一題」）。
- `start`：預設先顯示哪一層（通常 `'B'`）。

## LS.check(h, {q, options, tally})

```js
visual: (h) => LS.check(h, {
  q: '直角三角形三邊 6、8、10，哪一邊是斜邊？',
  options: [
    { t: '10', ok: true, why: '斜邊最長，在直角對面。' },
    { t: '8', why: '把「最後寫的數」當斜邊。' },
    { t: '6', why: '把「直立的邊」當斜邊。' }
  ]
})
```

- 每個錯誤選項都要對應一種**典型錯誤或迷思**，`why` 寫出成因。不要寫成單純「錯」。
- 學生用手勢或小白板同步作答；老師點右側數字計票，再按「揭曉」。
- 設 `tally: false` 可以不顯示計票。
- 判讀方式寫在左欄 `points` 或教案：例如「超過三成選 B，回到 2-2 重講」。

## LS.mistake(h, {who, q, steps, wrong, why, fix})

```js
visual: (h) => LS.mistake(h, {
  q: '直角三角形兩股 5、12，求斜邊。',
  steps: ['\\(c=5+12\\)', '\\(c=17\\)'],
  wrong: 0,
  why: '概念錯誤：把「平方和」當成「邊長和」。',
  fix: '\\(c^2=5^2+12^2=169\\)，\\(c=13\\)'
})
```

- `who` 預設「某位同學的解法（不公開姓名）」。**不得**放真實學生姓名或可辨識的資訊。
- `wrong`：錯誤步驟的序號（從 0 起算）。
- `why` 要標明錯誤類型：概念錯誤、程序錯誤或粗心失誤。
- 錯誤示例可以來自教師提供的真實作答（去識別化），或標註「預期錯誤」。

## LS.timer(h, {min, label, tips})

```js
visual: (h) => LS.timer(h, { min: 8, label: '獨立練習', tips: ['先看 B 層同學能否寫出平方式'] })
```

- 按「開始」才倒數。換頁後會自動停止。
- `tips` 寫給老師的巡視觀察重點，1～2 條。

## LS.exit(h, {q, ans, rubric})

```js
visual: (h) => LS.exit(h, {
  q: '梯子長 10 m，底端離牆 6 m，頂端多高？',
  ans: '8 m',
  rubric: {
    mastered: '列式正確且答 8 m → 下一節直接進入應用題',
    partial: '列式對但計算錯 → 下一節起步題再練一次',
    notyet: '把邊長相加 → 下一節小組補救，回到面積拼圖'
  }
})
```

- 出口題 2～3 分鐘可完成、答案容易快速檢查，不是示範題的機械重複。
- `rubric` 的三類各寫「判準 → 下一節安排」。

## LS.tally(h, {q, levels})

```js
visual: (h) => LS.tally(h, { q: '我能用畢氏定理求未知邊', levels: ['已掌握', '部分掌握', '尚未掌握'] })
```

- 老師點數字計票，長條圖即時更新。只記人數，不記姓名。
