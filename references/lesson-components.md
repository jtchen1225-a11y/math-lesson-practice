# 課堂元件 LS（lesson.js）使用說明

`lesson.js` 提供 9 個課堂元件，在投影片的 `visual: (h) => …` 內呼叫。每個元件對應 AGENTS 三項原則中的一個環節：

| 元件 | 用在 | 對應原則 |
|------|------|----------|
| `LS.goals` | 學習目標、本節總結、概念脈絡 | 每位學生知道本節要做到什麼 |
| `LS.tasks` | 起步題、分層練習、分層鞏固 | 原則一：每位學生都有明確任務（A／B／C＋提示階梯） |
| `LS.tiers` | 選擇你的挑戰（三層題目同頁一覽） | 原則一：學生看完三層再自己選層，分層不是固定標籤 |
| `LS.anim` | 動畫引入（分幕動畫＋字幕＋預錄語音，例：粵語旁白） | 引起動機、建立直觀；看完要學生說出發現 |
| `LS.check` | 講解中的理解檢查、診斷題、前測 | 原則二：教師能及時發現困難（全班同步作答＋計票＋迷思說明） |
| `LS.mistake` | 典型錯誤分析 | 原則二：分辨概念／程序／粗心錯誤；不公開學生身份 |
| `LS.timer` | 獨立嘗試＋巡視 | 原則一：給學生安靜思考時間 |
| `LS.exit` | 出口題 | 原則三：留下學習證據＋三類學生後續安排 |
| `LS.tally` | 自我評估、舉手統計 | 原則三：學生反思自己的理解 |

共通規則：

- **投影畫面是給學生看的**：階段名稱、小節名稱、左欄 `points`、計時頁的 `tips` 都寫成學生的任務或自我提醒（例：「抓錯偵探」「專注時間」「先找斜邊了嗎？」），不寫教師的動作（巡視、計票、判斷誰該補救）。教師用的說法寫在教案。

- 內容字串可含 HTML 與行內數學 `\\( \\)`（JS 字串內雙反斜線）。
- 元件只寫入 `h`，不要再對 `h.innerHTML` 另外賦值。
- 教學文字一律 28pt。右欄約 20 個中文字一行，**題目 1～2 行、每條提示 1 行**為原則。
- 按鈕逐步揭露（提示、答案、迷思、判準），初次畫面只顯示題目，所以 `?check` 量的是「初次畫面」。揭露後若超出欄高，欄位可以捲動，但仍建議縮短文字。
- 驗證工具只確認元件初次繪製沒有錯誤；**按鈕揭露後的內容（提示、答案、迷思說明）要人工點一遍確認**。

---

## LS.goals(h, {head, items, note})

```js
visual: (h) => LS.goals(h, {
  head: '本節學習目標',
  items: ['能說出直角三角形三邊的關係', '能求出直角三角形的未知邊'],
  note: '選填：一行補充'
})
```

## LS.tasks(h, tiers, {start})

```js
visual: (h) => LS.tasks(h, [
  { tier: 'A', q: '直角邊 3、4，斜邊是多少？', hints: ['斜邊在直角的對面。', '先算 \\(3^2+4^2\\)。'], ans: '5' },
  { tier: 'B', q: '斜邊 13、一股 5，另一股？', hints: ['斜邊的平方最大。'], ans: '12' },
  { tier: 'C', q: '為什麼 \\(1,1,2\\) 不能是直角三角形三邊？', ans: '\\(1^2+1^2\\neq2^2\\)，而且 1＋1 不大於 2' }
], { start: 'B' })
```

- `tier`：`'A'`（基礎支持）、`'B'`（核心達標）、`'C'`（延伸挑戰）；`name` 可自訂層名。
- `hints`：提示階梯，按一次「給提示」多顯示一條。依 AGENTS 支持次序排列：重讀題目 → 相關概念 → 部分線索 → 關鍵步驟。
- 三層圍繞**同一個核心概念**；C 層要求解釋、比較、推理或遷移，不是同型題加量。
- 只給一層時不顯示分頁，改顯示層標籤（適合「再試一題」）。
- `start`：預設先顯示哪一層（通常 `'B'`）。

## LS.check(h, {q, options, tally})

```js
visual: (h) => LS.check(h, {
  q: '直角三角形三邊 6、8、10，哪一邊是斜邊？',
  options: [
    { t: '10', ok: true, why: '斜邊最長，在直角對面。' },
    { t: '8', why: '把「最後寫的數」當斜邊。' },
    { t: '6', why: '把「直立的邊」當斜邊。' }
  ]
})
```

- 每個錯誤選項都要對應一種**典型錯誤或迷思**，`why` 寫出成因。不要寫成單純「錯」。
- 學生用手勢或小白板同步作答；老師點右側數字計票，再按「揭曉」。
- 設 `tally: false` 可以不顯示計票。
- 判讀方式寫在左欄 `points` 或教案：例如「超過三成選 B，回到 2-2 重講」。

## LS.mistake(h, {who, q, steps, wrong, why, fix})

```js
visual: (h) => LS.mistake(h, {
  q: '直角三角形兩股 5、12，求斜邊。',
  steps: ['\\(c=5+12\\)', '\\(c=17\\)'],
  wrong: 0,
  why: '概念錯誤：把「平方和」當成「邊長和」。',
  fix: '\\(c^2=5^2+12^2=169\\)，\\(c=13\\)'
})
```

- `who` 預設「某位同學的解法（不公開姓名）」。**不得**放真實學生姓名或可辨識的資訊。
- `wrong`：錯誤步驟的序號（從 0 起算）。
- `why` 要標明錯誤類型：概念錯誤、程序錯誤或粗心失誤。
- 錯誤示例可以來自教師提供的真實作答（去識別化），或標註「預期錯誤」。

## LS.timer(h, {min, label, tips})

```js
visual: (h) => LS.timer(h, { min: 8, label: '專注時間', tips: ['先找斜邊：直角對面那條', '已知斜邊？改用減法'] })
```

- 按「開始」才倒數。換頁後會自動停止。
- `tips` 是給學生看的自我檢查提醒，1～2 條。教師的巡視觀察重點寫在教案，不放在投影畫面。

## LS.exit(h, {q, ans, rubric})

```js
visual: (h) => LS.exit(h, {
  q: '梯子長 10 m，底端離牆 6 m，頂端多高？',
  ans: '8 m',
  rubric: {
    mastered: '列式正確且答 8 m → 下一節直接進入應用題',
    partial: '列式對但計算錯 → 下一節起步題再練一次',
    notyet: '把邊長相加 → 下一節小組補救，回到面積拼圖'
  }
})
```

- 出口題 2～3 分鐘可完成、答案容易快速檢查，不是示範題的機械重複。
- `rubric` 的三類各寫「判準 → 下一節安排」。

## LS.tally(h, {q, levels})

```js
visual: (h) => LS.tally(h, { q: '我能用畢氏定理求未知邊', levels: ['已掌握', '部分掌握', '尚未掌握'] })
```

- 老師點數字計票，長條圖即時更新。只記人數，不記姓名。

## LS.tiers(h, tiers)

```js
const TASKS = [
  { tier: 'A', fit: '想先把基本功做穩', q: '兩股 9、12，求斜邊。', hints: ['…'], ans: '15' },
  { tier: 'B', fit: '會求斜邊了', q: '斜邊 17、一股 8，求另一股。', hints: ['…'], ans: '15' },
  { tier: 'C', fit: '想挑戰說理由', q: '兩股都是 1，斜邊是整數嗎？', ans: '…' }
];
// 3-1 選擇你的挑戰：三層同時顯示
visual: (h) => LS.tiers(h, TASKS)
// 3-2 作答頁：同一組題目，分頁＋提示階梯＋答案
visual: (h) => LS.tasks(h, TASKS, { start: 'B' })
```

- A、B、C 三層題目**同一頁同時顯示**，讓學生先看全貌再選層；不顯示提示與答案。
- `fit` 用學生的口吻寫「適合誰」（例：「會求斜邊了」），不寫能力標籤（例：「程度差的同學」）。
- 和 `LS.tasks` 共用同一個題目陣列（寫成常數，兩頁都用），內容才不會不一致。
- 題目每題 1 行為原則；三題都 2 行時，720p 投影可能放不下（用 `--window 1310x862` 檢查）。

## LS.anim(h, {scenes, vb, lang})

```js
visual: (h) => LS.anim(h, {
  vb: '0 0 440 250',
  scenes: [
    { say: '呢個係直角三角形。', audio: 'audio/s1.mp3', dur: 6, d: k => SV.poly(...) },
    { say: '喺兩條股上面砌正方形。', audio: 'audio/s2.mp3', dur: 6, d: k => /* k 從 0 到 1 長出正方形 */ '' }
  ]
})
```

- 每一幕：`say`（字幕，投影 28pt，**1～2 行**）、`d(k)`（該幕的 SVG 片段，`k` 為 0～1 的進度；前面各幕自動以 `d(1)` 疊加）、`dur`（秒，最短播放時間）、`audio`（選填，預錄語音）。
- 第一幕的 `d(0)` 必須畫出東西（驗證工具會檢查圖形元素不可變成 0）。
- 播放：按 ▶ 才開始。每一幕播完 `dur` 秒**而且**語音講完才換下一幕；可暫停、可拖進度條、可關聲音；換頁自動停止。
- 沒有 `audio` 時，若電腦有 `lang`（預設 `zh-HK`）語音就由瀏覽器朗讀字幕；沒有就只顯示字幕。
- 進度條是 `<input type="range">`，驗證工具會掃過全部 0.01 步進值，檢查每一個畫面。
- SVG 中文字 `font-size` 至少 30（viewBox 寬 440 時），720p 投影才不會小於 28pt。

### 產生粵語語音（預錄 mp3）

1. 寫 `narration.json`（`text` 是「讀出來的字」：數字寫中文、a² 寫「a 嘅平方」）：
   ```json
   { "voice": "zh-HK-HiuGaaiNeural", "rate": "-5%",
     "items": [ {"file": "s1.mp3", "text": "呢個係直角三角形。兩條短邊叫做股，最長嗰條叫做斜邊。"} ] }
   ```
2. 用**已安裝 edge-tts** 的 Python 執行（本技能不會安裝套件）：
   ```powershell
   <有 edge-tts 的 python> "$S\scripts\make_audio.py" --config "output\<名稱>\narration.json" --out "output\<名稱>\site\audio"
   ```
3. 在 `chN.js` 的每一幕寫 `audio: 'audio/s1.mp3'`。

注意：edge-tts 會把 `text` 送到微軟 Edge 朗讀服務（需要網路，非正式公開介面）。旁白只放教學內容，不放學生姓名或個資。產生後 mp3 留在 `site\audio\`，上課播放不需要網路。沒有 edge-tts 或使用者不同意送出文字時，省略 `audio`，改用字幕（＋瀏覽器語音）。
